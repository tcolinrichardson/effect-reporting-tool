# Five Inferential Frameworks: Summary Table

Under Gaussian likelihood with regular conditions (moderate-to-large samples, no boundary parameters, no informative stopping rules), the following five frameworks produce numerically equivalent outputs but interpret them differently. This table summarizes what each framework licenses you to say.

Running example throughout: a study of a protective intervention with RR̂ = 0.43, 95% CI [0.22, 0.84], SE on log scale = 0.341, two-sided p = 0.014, MID = 0.82.

---

## Summary table

| Framework | Plain-language summary | What it produces | What you can correctly say | What you can say about the MID | What you can't say | Key references |
|---|---|---|---|---|---|---|
| **Bayesian (flat prior)** | We treat the true effect as unknown but having a probability distribution. The data update that distribution. With a flat starting belief (any value is initially equally likely), the result is a probability distribution over possible true effects, centered on our estimate. From this distribution, we can read off the probability that the true effect falls in any range. | A posterior distribution over θ representing degrees of belief about the parameter, given the data and the prior. Under flat prior, posterior = Normal(β̂, SE²). | "There is a 99.3% posterior probability that the true RR is below 1." / "The 95% credible interval is [0.22, 0.84]." / "The posterior mean is 0.43." | "There is a 97.1% posterior probability that the true RR is below the MID of 0.82, i.e., that the intervention produces a meaningfully protective effect." | Don't claim this is purely "what the data say" — the flat prior is a substantive assumption that all parameter values are equally plausible a priori. Don't claim the posterior incorporates external knowledge unless you've used an informative prior. | Bayes (1763), Laplace (1814), Lindley & Smith (1972), Gelman et al. *Bayesian Data Analysis* |
| **Confidence distribution** | We construct a distribution-valued object that summarizes how the inference procedure behaves. Reading off this object tells us at what confidence level any range of values would have been asserted by the procedure. This is a statement about the procedure's long-run behavior, not a Bayesian belief about the parameter. | A distribution-valued frequentist object H(θ) whose value at θ₀ gives the confidence that θ < θ₀. Frequency property of the inference procedure. | "Confidence that RR < 1 is 99.3%." Interpretation: across the class of inference procedures generated by this CD, 99.3% confidence intervals at the appropriate one-sided level would have their full range below 1 when this is the true configuration. / "The 95% confidence interval is [0.22, 0.84]." | "Confidence that RR < MID = 0.82 is 97.1%. That is, an appropriate frequentist procedure would assert RR < 0.82 at confidence level 97.1% or higher; in repeated sampling, this assertion would hold its claimed coverage." | Don't claim this is a Bayesian probability statement about RR. Don't import Bayesian language ("probable," "credible") — strictly, this is a frequency claim about the procedure, not a belief about the parameter. | Cox (1958), Fraser, Efron (1993), Schweder & Hjort (2016) *Confidence, Likelihood, Probability*, Xie & Singh (2013) |
| **Compatibility curve** | For every candidate value of the true effect, we ask how compatible that specific value is with the observed data (using a p-value or related measure). The result is a curve showing compatibility at every point in the parameter space. It tells us which values are well-supported and which are inconsistent, but it doesn't aggregate into a single probability over ranges. | A function p(θ₀) showing the two-sided p-value testing each candidate value θ₀. Compatibility at each point in parameter space; no cumulative interpretation. | "The compatibility of RR = 1 with the data is p = 0.014 (s ≈ 6.2 bits against this null)." / "The 95% compatibility interval is [0.22, 0.84]." / "RR values outside [0.22, 0.84] are inconsistent with the data at the 5% compatibility level." / "RR = 0.43 is the value most compatible with the data." | "The compatibility of the MID (RR = 0.82) with the data is p = 0.059 (s ≈ 4.1 bits against the MID as null). The MID is on the boundary of plausibility — the data are weakly consistent with the MID itself but more strongly consistent with smaller (more protective) RR values." Note: cannot directly report a probability that RR < MID. | Don't claim cumulative probabilities like "P(RR < 1)." Don't compute or report area under the curve as if it were a probability mass. The framework is about compatibility at individual values, not over ranges. | Cox (1958), Greenland (1999, 2019), Rafi & Greenland (2020), Greenland *et al.* (various works on s-values) |
| **Bootstrap** | We resample the original data many times (with replacement) and recompute the estimate from each resample. The collection of resampled estimates shows how the estimate might vary from sample to sample. From this collection we can compute summaries: standard error, percentile intervals, and the proportion of resampled estimates beyond any threshold. | The empirical distribution of β̂* across many resamples (with replacement) of the original data. Approximates the sampling distribution of the estimator. | "Across 10,000 bootstrap resamples, 99.3% had estimates below 1." / "The 95% bootstrap percentile interval is [0.22, 0.84]." / "The bootstrap standard error of RR̂ is 0.34 (on the log scale)." | "Across 10,000 bootstrap resamples, 97.1% had estimates below the MID of 0.82. The resampling distribution suggests the estimator would exceed 0.82 in only about 3 percent of replications under the data-generating process the bootstrap approximates." | Don't claim the bootstrap distribution is the posterior over θ — it's the sampling distribution of the estimator. Don't claim bootstrap percentiles are Bayesian probability statements about the parameter. Don't use bootstrap when the estimator is non-smooth, near a boundary, or for small samples without specific bootstrap corrections. | Efron (1979), Efron & Tibshirani (1993) *An Introduction to the Bootstrap*, Davison & Hinkley (1997) |
| **Likelihood inference** | We compute the likelihood function: how well each possible true value explains the observed data. The value that best explains the data is the maximum likelihood estimate; nearby values are nearly as well supported; distant values are progressively less supported. We can directly compare how much better one value is supported than another, using likelihood ratios. | The likelihood function L(θ \| data) plotted over the parameter space. Relative support for each value of θ, with the MLE being the value with maximum support. | "The data most strongly support RR = 0.43 (the MLE)." / "Values of RR outside [0.22, 0.84] are at least 8 times less supported than the MLE (1/8 support interval)." / "The data support RR = 0.43 over RR = 1 by a likelihood ratio of approximately 21:1." | "The MID (RR = 0.82) is less well supported by the data than the MLE by a likelihood ratio of approximately 1/6. Put differently: any RR more protective than the MID is more strongly supported than the MID itself; the data favor 'meaningful protective effect' over 'just barely meaningful' by a moderate margin." | Don't claim posterior probabilities — likelihood inference doesn't normalize the likelihood into a probability distribution. Don't claim confidence or compatibility statements without invoking sampling-distribution machinery. Don't treat the integral over the likelihood as a probability. | Fisher (1922), Edwards (1972, 1992) *Likelihood*, Royall (1997) *Statistical Evidence*, Pawitan (2001) *In All Likelihood* |

## Numerical equivalence across frameworks (running example)

For the example study (RR̂ = 0.43, SE_log = 0.341, MID = 0.82), all five frameworks produce these matching outputs:

| Quantity | Value | Bayesian framing | CD framing | Compatibility framing | Bootstrap framing | Likelihood framing |
|---|---|---|---|---|---|---|
| Point estimate | 0.43 | Posterior median/mean | MLE / CD median | Peak of compatibility curve | Bootstrap mean | MLE |
| 95% interval (RR scale) | [0.22, 0.84] | 95% credible interval | 95% confidence interval | 95% compatibility interval | 95% bootstrap percentile interval | ~1/14 support interval (approximate) |
| Test against RR = 1 | p = 0.014 | P(RR < 1) = 0.993 | Confidence(RR < 1) = 0.993 | Compatibility(RR = 1) = 0.014 | 99.3% of bootstrap draws < 1 | LR(RR=1 vs MLE) ≈ 1/21 |
| Test against RR = MID = 0.82 | p ≈ 0.059 | P(RR < 0.82) = 0.971 | Confidence(RR < 0.82) = 0.971 | Compatibility(RR = 0.82) = 0.059 | 97.1% of bootstrap draws < 0.82 | LR(RR=0.82 vs MLE) ≈ 1/6 |

The numbers in each row are the same value, presented in the vocabulary of each framework. The frameworks disagree about what kind of statement they license, not about the underlying arithmetic.

## Quick guide: which framework for which audience

| Audience | Best framing | Why |
|---|---|---|
| Non-technical staff, program officers | Bayesian (flat prior) | Probability language is most intuitive |
| Sophisticated frequentists, regulatory reviewers | Confidence distribution | Frequentist credentials with probability-like outputs |
| Methodological reviewers, Greenland-influenced epidemiologists | Compatibility curve | Most epistemically conservative; explicit about what's not claimed |
| Empirical economists, applied researchers comfortable with resampling | Bootstrap | Concrete computational interpretation; familiar from robust SE work |
| Statisticians, philosophers of inference, likelihoodist traditions | Likelihood inference | Cleanest expression of evidence as relative support |

For most reports, the Bayesian and CD framings cover 90% of users. The other three are useful supplementary content for audiences that specifically prefer them or for documentation that demonstrates methodological breadth.

---

## Important caveats

1. **The numerical equivalence is conditional on regularity.** Under Gaussian likelihood with no informative stopping rule, moderate samples, and no boundary parameters, all five frameworks produce matching outputs. In non-regular cases (sequential trials, small samples, rare events, boundary parameters), they genuinely disagree and the choice matters.

2. **The frameworks are not unified by a shared principle.** Bayesian and likelihood frameworks satisfy the Likelihood Principle; the others (CD, compatibility, bootstrap) violate it. The numerical convergence in regular cases is a happy accident of Gaussian structure, not principled unification.

3. **The "what you can't say" column is doing real work.** Mixing claims across frameworks (e.g., reporting compatibility-curve outputs but then claiming cumulative probabilities) is a common error. Each framework licenses specific types of statements; staying within those licenses is part of using the framework honestly.

4. **None of the frameworks incorporate external information without explicit extension.** Bayesian inference can, via informative priors. The others can't, without leaving the framework and applying informal discounting. So all five are versions of "what the data alone say" in the regular case. To bring in replication, publication bias, or domain priors, you need to step outside any of these frameworks.
